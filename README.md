# Recomendador de Películas

## Pasos para correrlo
1. Abre esta carpeta en Visual Studio Code.
2. En la terminal (Ctrl + ñ), dentro de la carpeta, ejecuta:
   flutter create .
   (genera las carpetas android, ios, web... sin tocar tu código en lib/)
3. Abre `lib/config.dart` y pega tu API key de TMDB.
4. Ejecuta:
   flutter pub get
   flutter run
